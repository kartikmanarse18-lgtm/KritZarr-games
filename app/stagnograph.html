About Kritzaar Vault

A private way to carry files, notes, photos, or video inside a picture that looks completely ordinary — opened only by the passphrase you set.

Pixel mode encrypts your files with AES‑256‑GCM, then writes the encrypted bytes into the least‑significant bits of the cover picture's own pixels. The output is a normal PNG with the resolution's usual file size — there's no trailing data and no size mismatch for an app or viewer to notice.

Attachment mode encrypts the same way, then seals the result on after the picture's existing data. It supports larger payloads (like video) and keeps animated GIFs animated, but the file is measurably bigger than a plain version of that picture.

Your passphrase is run through PBKDF2 (310,000 rounds, SHA‑256) to derive a key, which encrypts everything with AES‑256‑GCM before it ever touches the picture. The passphrase is never stored or sent anywhere — it only exists in your browser while you type it. If you lose it, the data cannot be recovered.

Any app that recompresses images — WhatsApp, iMessage, Instagram, most social platforms — will destroy the hidden data the moment it's sent as a photo. Always send and save the file as a document/file attachment, never as a "photo", and have the recipient download it rather than just viewing the in‑chat preview.

Pixel mode defeats casual and app‑level inspection — the normal bar for "looks totally normal." No method can promise zero detectability against a determined forensic analyst holding the original cover image for comparison. Pixel‑mode capacity depends on the cover photo's resolution; the Hide tab shows how many KB a chosen picture can carry.

Everything — encryption, pixel embedding, and reveal — runs locally in your browser. Nothing is uploaded anywhere.
